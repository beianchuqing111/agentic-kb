# 红外测温作业指导书

## 一、适用对象与测温时机

红外测温是发现设备过热性缺陷的主要手段,适用于导线接头、线夹、套管、避雷器和绝缘子等部位。
测温时机对结果影响极大,负荷高峰期测得的温度才具有代表性,轻载时段的温度数据参考价值有限。
输电线路的测温应当安排在用电高峰时段进行,变电站内的设备测温则应当结合负荷曲线确定。
日出前后和日落后一小时内,设备表面温度受日照和环境影响剧烈变化,不宜作为测温时段。
雨雪天气和风速大于五米每秒时不宜开展测温,水膜蒸发和强制对流都会显著改变表面温度。

## 二、仪器参数设置

发射率是最关键的参数,未做表面处理的金属发射率很低,直接测量会严重低估温度。
常用的发射率取值如下表,现场应当按被测对象的表面状态选择,不得一律使用默认值。

| 被测表面状态 | 发射率取值 | 典型对象 |
| --- | --- | --- |
| 氧化后的铝表面 | 0.30 | 导线、线夹 |
| 光亮铝表面 | 0.09 | 新安装金具 |
| 涂漆金属表面 | 0.95 | 涂装构架 |
| 瓷套表面 | 0.92 | 绝缘子、套管 |
| 橡胶与硅胶表面 | 0.90 | 复合绝缘子伞裙 |

距离系数决定仪器的空间分辨率,测温距离与目标尺寸之比不得超过仪器标称的距离系数。
大气透过率在长距离测温时不可忽略,距离超过三十米应当按仪器说明进行透过率修正。
测温仪应当每年送检一次,并在使用前后核对黑体炉读数,偏差超过两开尔文的仪器不得使用。

## 三、测量方法与判据

测量时应当先对目标区域进行整体扫描,发现温度异常区域后再进行精确测量并记录最高温度点。
同一部位应当测量三次取最高值,单次读数容易受瞬时气流影响而不能代表真实温度。
判据以相对温差和温升两种方式表达:相对温差反映同组设备之间的不平衡程度,温升反映设备自身的发热水平。
相对温差等于发热点温升与参照点温升之差除以发热点温升,超过百分之八十即判定为严重缺陷。
温升超过十开尔文时应当列入重点观察,不同设备类别的温升限值应当按相应专业规程执行。

## 四、数据分析与判定

上述参数设置完成后,该系统会自动完成图像的温度提取和异常点定位,无需人工逐点判读。
该方法的优势在于把环境温度、负荷电流和温度数据放在同一个坐标系下比较,能看出单次测量看不出的趋势。
采用上述判据时应当注意,同组设备的相互比较比绝对值更可靠,因为环境条件的系统性影响会被相互抵消。
该系统对历史数据的依赖较强,首次投运或历史数据缺失的设备应当以相互比较法为主。
上述做法在迎峰度夏和迎峰度冬期间尤其重要,因为这两个时段的负荷变化速率最快,趋势判断的价值最高。
需要说明的是,上述所有判据都建立在负荷电流相对稳定的前提下,负荷剧烈波动时应当以绝对温升为准。

## 五、记录与报告

每一次测温都应当记录环境温度、湿度、风速、负荷电流和测量距离,缺少这五项数据的温升无法复现。
图像应当同时保存可见光照片和红外热图,只用红外热图在消缺时往往找不到对应部位。
测温报告应当包含缺陷等级判定和处理建议,只出图不作判定的报告无法直接用于消缺安排。
测温数据应当归档保存,保存期限不少于三年,并与历次数据合并形成趋势曲线。
发现危急缺陷时应当立即报告值班调度,不得等到出具正式报告后再上报。
